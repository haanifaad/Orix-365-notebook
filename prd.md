PRD — Notebook

Product Name: Notebook
Version: v0.1 MVP
Product Type: Desktop text editor
Primary Goal: Build a fast, lightweight, offline-first notebook application.

1. Vision

Notebook is a simple, fast desktop application for creating, editing, organizing, and saving text.

The long-term vision is for Notebook to become the foundation of a larger productivity ecosystem.
